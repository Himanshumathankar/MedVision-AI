# MedVision AI

MedVision AI is a production-grade, cross-platform AI healthcare platform for medical scan analysis. The initial module focuses on breast cancer detection with explainable AI outputs (Grad-CAM and SHAP) and reporting.

## Monorepo Structure

- frontend: Flutter 3.x cross-platform app
- backend: FastAPI inference and reporting APIs
- docker: Docker and compose setup
- docs: Architecture, API, and deployment guides

## Quick Start

1. Install Flutter SDK and run the frontend.
2. Create a Python virtual environment and install backend requirements.
3. Use docker-compose for PostgreSQL and Redis.

See docs for detailed instructions.
